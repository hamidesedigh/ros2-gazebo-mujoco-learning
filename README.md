# ROS2, Gazebo, and MuJoCo Learning Repository

## 📌 Overview
This repository documents my journey learning **ROS 2**, **Gazebo**, and **MuJoCo** for robotics control and simulation.  
It combines my expertise in **formal control theory** with hands-on practice in **Python control libraries**.

## 🎯 Goals
- Build strong foundations in ROS 2 communication and control.
- Simulate robotic arms (e.g., PUMA 560) in Gazebo.
- Explore reinforcement learning environments in MuJoCo.
- Integrate ROS 2, Gazebo, and MuJoCo for hybrid experiments.
- Document expected vs. observed behaviors for verification.

## 📂 Repository Structure
- `docs/` → Notes and specification-style documentation.
- `examples/` → Minimal working demos in ROS 2, Gazebo, MuJoCo, Python control.
- `projects/` → Hybrid experiments combining multiple tools.
- `logs/` → Weekly learning journal and troubleshooting notes.

## 🛠️ Roadmap
- **Weeks 1–2:** ROS 2 basics + Python control warm-up.
- **Weeks 3–4:** Gazebo simulation (PUMA 560).
- **Weeks 5–6:** MuJoCo RL environments.
- **Weeks 7+:** Integration projects (ROS 2 + Gazebo + MuJoCo).
